## English — Requirements and changes

Minecraft 1.20.1, Forge 47.4.10–47.x, Java 17. ZoneLevelUp beta29-r57 or newer below beta30 is required on both sides; this release set uses r58. Core 2.1.4–2.x is needed by LevelUp server, not directly by the Dungeons client. Crates currency and Corail Tombstone are optional integrations; no Trek installation is required.

Beta10 adds seven shared MasmorrasZ for levels 20/40/60/80/100/120/150, entered without ZParty. A five-minute queue starts with five players or its enrolled group when time expires. Guardians open all shared chests on victory; defaults grant each member 100 virtual coins and 500 exact LevelUp XP. Death retains the same session with native respawn and five-second ordinary-damage protection; `/zsalir` is voluntary exit. Weekly wins close Monday 00:00UTC with a default 500-coin first-place prize. Install the beta10 pair and LevelUp r58 pair on Forge 47.4.10+. Core is required through LevelUp server only; preserve dungeon/player data and review broad default loot before use.

Use LevelUp → MUNDO → MasmorrasZ or `/masmorrasz lista`, then `/masmorrasz entrar nivel_20` when eligible. Leave with `/zsalir`. Operators configure each tier and reload only when no session/preparation is active.

## Shared sessions / Partidas compartidas

One session per structure; no ZParty required. Minimum levels are 20, 40, 60, 80, 100, 120, 150. Preparation places blocks in batches without permanent tickets, keeps the roster closed and leaves players at their original location until ready. Only original members can reconnect into a started session. / Una partida por estructura, preparación por lotes sin tickets permanentes y lista cerrada. Solo miembros originales pueden volver a partida iniciada.

The central guardian is available from the start; normal rooms activate in order when approached. Victory is recorded immediately on guardian death, grants once, removes encounter mobs and opens all chests. Loot time ends with return to shared Overworld spawn. Running out of combat time grants no victory. / Guardián disponible desde inicio; salas por proximidad. Su muerte registra victoria una vez, abre cofres y retira mobs. Tiempo agotado no premia.

Death preserves membership and native respawn returns inside the same session after approximately one second, with five seconds of ordinary-damage protection. Inventory is not copied or restored. Corail retains grave ownership/inventory rules; administrator help may be needed if cooldown starts before recovery. / Morir conserva pertenencia y reaparece dentro sin copiar inventario. Corail conserva reglas; tras terminar puede necesitarse ayuda administrativa para tumba.

Direct friendly attacks and supported owner-aware projectiles/summons/TNT are blocked. Other mods with unowned custom damage require testing. Ordinary external teleports are restricted during the run; internal movement, recovery, system exits and OP 2 administration remain possible. / Se bloquea daño aliado reconocido y viajes externos ordinarios; movimientos internos, recuperación, salidas y administración OP 2 siguen disponibles.

Weekly ties favor whoever reached the winning count earlier, then UUID for exact ties. Offline rewards persist; empty missed weeks do not create prizes. / Empates por momento de alcanzar victorias, luego UUID; premios offline persisten, semanas vacías no inventan premios.

## Installation / Instalación

Stop the affected instance, back up world/configuration and replace only the previous same-mod/same-side JAR. Keep one JAR per mod per instance and preserve player data. / Detén la instancia correspondiente, respalda mundo/configuración y sustituye solo el JAR del mismo mod y lado. Conserva un JAR por mod e instancia y los datos de jugador.
