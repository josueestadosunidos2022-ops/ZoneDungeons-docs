# ZoneDungeons beta15

## 1.0.0-beta15 · Entradas y edición / Entrances and editing

### Español

Las entradas pueden quedar lejos de la primera sala. Los corredores permiten llegar al siguiente encuentro y las salas futuras siguen cerradas hasta que corresponda. Puedes editar una expedición publicada mediante sus comandos de administración. Los cambios se guardan en un borrador hasta validar y publicar; se respalda el original. El editor se bloquea durante una partida activa y permite descartar cambios pendientes.

Instala beta15 en cliente y servidor, con ZoneLevelUp beta29-r70 o posterior de la rama beta29 en ambos lados. Minecraft Forge 1.20.1 y Java 17.

### English

Entrances can sit farther from the first room. Corridors allow travel to the next encounter while later rooms remain closed. Edit a published expedition with its admin commands. Changes stay in a draft until validated and published, with a backup of the previous definition. Active sessions lock editing. Pending changes can be discarded.

Install beta15 on client and server, with matching ZoneLevelUp beta29 builds at r70 or later. Minecraft Forge 1.20.1 and Java 17.
