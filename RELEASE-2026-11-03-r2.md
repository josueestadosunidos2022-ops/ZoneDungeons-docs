# ZoneDungeons 1.0.0-beta9 — SERVER / CLIENT

## English

Five progressive private expedition templates in the empty zonedungeons:expediciones dimension. Physical instances have independent enemies, progress and personal room-chest/final loot. Solo or nearby connected ZParty group; bounded instance allocation and at least two chunks between new structures. Requires matching LevelUp beta29-r53+ below beta30; use beta9 on both sides.

Minecraft 1.20.1 / Forge 47.4.10+ compatible 47.x / Java 17. Protected public Beta. Replace only the previous JAR for this side with the instance stopped; preserve world, character data and TOML. No sources, private mappings or production data. Archive/isolated tests do not certify full modpack multiplayer or render performance.

## Español

Cinco plantillas progresivas de expediciones privadas en la dimensión vacía zonedungeons:expediciones. Copias físicas con enemigos, progreso y botín personal de cofres y jefe. En solitario o con ZParty conectado cercano; límites de instancias y separación mínima de dos chunks entre estructuras nuevas. Requiere LevelUp beta29-r53+ anterior a beta30 y Dungeons beta9 en ambos lados.

Minecraft 1.20.1 / Forge 47.4.10+ compatible 47.x / Java 17. Beta pública protegida. Sustituye solo el JAR anterior del mismo lado con la instancia detenida; conserva mundo, personajes y TOML. Sin fuentes, mappings privados ni datos de producción. Las pruebas aisladas no certifican multijugador completo ni rendimiento gráfico.
